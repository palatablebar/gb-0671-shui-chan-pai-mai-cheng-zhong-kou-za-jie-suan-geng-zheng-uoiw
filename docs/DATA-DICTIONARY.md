# 数据定义

票号与原始编号均为字符串，保留前导零。称重支持 kg、公斤与 t，统一为 kg，单价为 CNY/kg。
每票可由毛重行与皮重行各带一个可选 `boat`（船名）与 `id_tail`（证件尾号），均为字符串，尾号保留前导零；船名与尾号只作归户证据，不参与计价。毛重与皮重按票号和版本配对，品类、单价、扣杂率与更正目标必须一致。计价重量=(毛重−皮重)×(1−扣杂率)，先量化到0.001kg，再乘单价，金额四舍五入到0.01CNY。
每票第一版不填写 replaces。后续版本只能替代当前生效版，分支或缺基版整票阻断结算。已支付额为各版本中最大累计已付值，待付=最终应付−累计已付；负待付表示待收回。
同编号同原值仅计一次；同编号不同原值全部隔离。空文件、全空行和仅表头分别报错。原始输入计数包括空行及重复表头，对账会分别解释。
船户归户：证件尾号是权威归属。同票毛皮尾号不一致整票不并。无尾号时船名仅在本批唯一对应一个尾号时临时补证并标记，否则不并、金额进暂存。户级总额=成交票总额=可付+暂存，差额必须为0。

发布：`publications` 以批次 sha256 为主键，重复发布同一证据只返回已有记录，不新增户级行；`households` 按（证据, 归户户键）唯一；`vouchers` 以源字节 sha256 保存原始过磅凭证，只增不删。发布在单事务内完成，任何失败回滚并保留旧版归属。

归档封存保存逐版证据、隔离原因、归户结果和运行摘要，非支付执行系统。数据使用虚构编号，不连接实际支付渠道。
